## Priority Issues
### [P1] Hero 開鍋狀態被 CSS 隱藏，使用者在關鍵時刻看不到目前狀態
- **Why it matters**：JS 在 index.html:306–366 每 60 秒更新 `.open-now-text` 為「現在開鍋中・到 21:30」／「還有 X 分鐘開鍋」，也切換 is-open/is-closed 並標今日列；但 styles.css:37 `.hero .open-now{display:none}` 使首屏那一份完全不可見。同一份狀態又因 `.open-now--head` 在 ≤920px 隱藏（styles.css:308），手機使用者完全不知道現在能不能吃。狗狗 Persuade 時刻失去最強的 reassurance。
- **Fix**：移除 hero 的 display:none 改顯眼；手機版保留一行緊湊「現在開鍋中・到 21:30」取代隱藏，並保留淡色靜態備援於關 JS 時顯示。hero-bottom（L116）與 header 狀態不得同時存在，應二選一。
- **Suggested command**: `/impeccable polish`
